Tips for a signature that pastes cleanly:
  • Use inline CSS (style="…") — Outlook web and Gmail strip <style> blocks.

Admin guide

1. Create the template

  1. Enter your school name, logo URL, address and website, then click Build template from these details.
  2. Use the live preview to check the design. Click the placeholder buttons (full name, job title…) to insert labels that get replaced per person.
  3. If you know HTML, you can refine the design further under Advanced: edit the HTML. Keep styling inline — Outlook web and Gmail ignore <style> blocks.

2. Save & share your template

  • Save template stores it in this browser (you do not need to re-enter it next time).
  • Copy share link encodes the template into the web address. Open that link on any computer to get your saved design — the template rides inside the URL, so nothing is stored on a server.
  • Export (.json) downloads a backup file; Import (.json) restores it. Keep a copy in case a browser’s saved data is cleared.
  • To send a ready-made signature to a staff member, they can open your share link and enter their own details on the “Add your staff” tab.

3. Add (or update) your staff

  1. Download the CSV template, fill it in (or export from your HR/admin spreadsheet), then upload it.
  2. Signatures appear as cards — click Copy and paste into each person’s Outlook or Gmail settings, or send them the file via Download .html.
  3. When you recruit, re-upload the updated CSV — every signature rebuilds instantly.

Ask staff to follow the staff guide, which covers Outlook web and Gmail step by step.

4. Privacy & UK data protection

This site is designed to make data protection easy:

  • No server-side storage. The tool is a static page: templates, CSV files and generated signatures exist only in the visitor’s browser.
  • Minimal personal data. Typically names and job titles only — low sensitivity. If you include emails/phones, that is still personal data under UK GDPR, so treat the CSV like any school record (don’t share the file externally).
  • Hosted logos. Keep the image URL on your school’s own hosting (e.g. SharePoint) so image requests stay within your control.
  • Host this page on any static host (GitHub Pages, Netlify, Azure Static Web Apps…). Because it stores nothing, there’s no database to secure and no processor to add to your record of processing.

5. FAQ

Outlook shows the logo as a broken/blocked image. Outlook blocks external images until a receiver clicks Download pictures or allows the sender. Ask staff to Allow this sender once, and test-sign to a colleague.

Gmail doesn’t show my logo. Gmail warps through its image proxy and normally loads hosted images automatically. If it looks broken, check the logo URL is public and doesn’t require sign-in.

Pastings lose the layout. Webmail lightly rewrites pasted content. Keeping the design to a single <table> with inline styles gives the most reliable result. If colours shift, view it as “plain text signature made pretty” — small tweaks are expected.

The copy button did nothing. Some browsers block clipboard writes. Use Download .html instead: open the file, select its content (Ctrl+A) and copy (Ctrl+C), then paste into the signature box.

Where are signatures stored? Outlook web: Settings → Mail → Compose and reply → Email signature. Gmail: Settings → See all settings → Signature. Details are on the staff guide.
