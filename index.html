Admin guide

1. Create the design

  1. Enter your school name, logo URL, address and website.
  2. In Signature fields, switch on exactly what should appear (e.g. Name, Job title, School name, Email, Website) and switch off the rest — for example Mobile, Telephone and Department. Switched-off fields are hidden from the preview and never appear in signatures; the staff form and CSV skip them.
  3. Choose the signature colour and click Build template from these details.
  4. Check the live preview. If you know HTML, refine the design under Advanced: edit the HTML. Keep styling inline — Outlook web and Gmail ignore <style> blocks.

2. Save & share your design

  • Save template stores the design and staff list in this browser.
  • Copy share link encodes the design into the web address — open it on any computer to get the exact same set-up. Nothing is stored on a server.
  • Export (.json) downloads a backup file; Import (.json) restores it. Keep a copy in case a browser’s saved data is cleared.

3. Add your staff

  1. Either type each person in on Step 2 or download the CSV template (which contains only your switched-on fields), fill it in, and upload it.
  2. The staff list shows everyone ready — you can Preview each signature, Edit a person’s details or Delete them.
  3. When you recruit, re-upload the updated CSV — every signature rebuilds instantly.

4. Generate & hand out signatures

  1. Go to Step 3 · Generate signatures.
  2. Use Copy against each person and paste into their Outlook or Gmail, or Copy all for a batch.
  3. Download ZIP bundles one .html file per person — the quickest way to distribute everything at once.

Ask staff to follow the staff guide, which covers Outlook web and Gmail step by step.

5. Privacy & UK data protection

This tool is designed to make data protection easy:

  • No server-side storage. The tool is a static page: the template, CSV files and generated signatures exist only in the visitor’s browser.
  • Minimal personal data. Typically names and job titles only — low sensitivity. If you include emails or phones, that is still personal data under UK GDPR, so treat the CSV like any school record (don’t share the file externally).
  • Hosted logos. Keep the image URL on your school’s own hosting (e.g. SharePoint) so image requests stay within your control.
  • Because nothing is stored, there is no database to secure and no processor to add to your record of processing.

6. FAQ

Outlook shows the logo as a broken/blocked image. Outlook blocks external images until a receiver clicks Download pictures or allows the sender. Ask staff to Allow this sender once, and test-sign to a colleague.

Gmail doesn’t show my logo. Gmail serves images through its proxy and normally loads hosted images automatically. If it looks broken, check the logo URL is public and doesn’t require sign-in.

Pasting loses the layout. Webmail lightly rewrites pasted content. Keeping the design to a single <table> with inline styles gives the most reliable result. If colours shift, view it as “plain text signature made pretty” — small tweaks are expected.

I switched a field on but it still doesn’t appear. The built-in template contains all fields, so switching a field on makes it appear immediately. If a very custom template is missing that placeholder, add it under Advanced: edit the HTML.

The copy button did nothing. Some browsers block clipboard writes. Use Download .html instead: open the file, select its content (Ctrl+A) and copy (Ctrl+C), then paste into the signature box.

Where are signatures stored? Outlook web: Settings → Mail → Compose and reply → Email signature. Gmail: Settings → See all settings → Signature. Details are on the staff guide.
